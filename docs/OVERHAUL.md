## 1. Architecture (audited 2026-10-31)

- Static site generated by `pipeline/website.py` (Python 3.9, f-string templates, one 170 KB module) into `web/dist`,
  deployed to Cloudflare Pages project `patentyard` by `pipeline/pipeline.py publish` (every ~2 h, LaunchAgent + loop).
- Pages Functions (`web/functions`): patent pages, drawings, kit data and card search read packed shards (PYS2);
  world records (`_world.js`) read from Pages projects `patentyard-cards` / `patentyard-details`.
- Cron Worker `web/watch` (patentyard-watch, KV `reinstated`) checks the Gazette daily for reinstatements.
- Browser JS: plain ES modules in `web/static/assets/js`, no bundler, no npm dependencies in the repo.
- Accounts: Supabase (`web/supabase/schema.sql`): profiles, reservations (RPC only), ideas (RLS), messages (insert only).
- Third parties loaded by pages: Google Fonts, jsDelivr (supabase-js), cdnjs (jsPDF, studio/kit only), Supabase.
- Tests: `pipeline/test_pipeline.py` (unit), `web/dev/smoke.js` (browser click-through with mock backend).
- Editorial notes (`pipeline/curation.json`: name, hook, twist, build level) and Opportunities write-ups
  (`pipeline/opportunities.json`) were drafted with Claude during data preparation, offline. No AI runs on the servers.

## 3. Design decisions (made 2026-10-31)

- Type: IBM Plex Sans for the interface and Patent Yard's words; IBM Plex Mono for identifiers, dates and data;
  IBM Plex Serif for original patent text (abstract, claims, description), so source text always reads differently from ours.
  Self-hosted woff2.
- Color: warm drafting-paper light theme and graphite dark theme, ink text, one accent: redline (the drafting correction
  red), used for primary actions, focus and the mark. Status colors fixed site-wide and always paired with a word:
  expired = green, lapsed (can be reinstated) = amber, likely abandoned (inferred) = slate with a dashed edge,
  no longer free = red.
- Surfaces: hairline borders, small radii (6 controls / 10 panels), no glow, no gradient text, no corner brackets.
  Drawings sit on a white sheet with a mono caption strip (FIG / sheet / number), the one place the patent-sheet idea shows.
- Motion: one easing curve and three durations; cross-document view transitions; the home drawing plotter; card hover
  is a border/shadow shift only; everything off under Reduce motion (OS or site setting).
